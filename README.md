# Projet 2.1 — Page de Profil Personnel (HTML Sémantique)

## Description du projet

Ce projet a été réalisé dans le cadre de ma formation **Akieni Academy**.

Il s’agit du livrable de la **PHASE 2 · MODULE 1 — SEMAINE 2 : HTML - Structure & Sémantique**.

L’objectif principal de ce module est de comprendre et maîtriser la structure d’une page HTML en utilisant correctement les balises sémantiques, tout en respectant les bonnes pratiques d’accessibilité et de validation.

---

## Objectifs de la semaine

- Comprendre la structure d'une page HTML
- Utiliser les balises sémantiques correctement
- Créer une page HTML valide et accessible
- Utiliser les DevTools pour déboguer le code

---

## Description du projet

Le projet consiste à créer une **page de profil personnel en HTML pur**, sans CSS.

Cette page doit représenter un profil simple et structuré contenant les éléments suivants :

- Un titre principal (`h1`) représentant le nom
- Une photo de profil (`img`)
- Une biographie sous forme de paragraphes
- Une liste de compétences (`ul`)
- Une section de formation (`dl`)
- Des liens vers les réseaux sociaux
- Un formulaire de contact simple (“Contactez-moi”)

---

## Structure du projet

Le projet est composé d’un fichier principal :

```bash
index.html
```

---

## Balises utilisées

Ce projet met en pratique les balises sémantiques HTML suivantes :

- `<header>`
- `<main>`
- `<section>`
- `<footer>`
- `<h1> - <h6>`
- `<p>`
- `<img>`
- `<ul> / <li>`
- `<dl> / <dt> / <dd>`
- `<a>`
- `<form>`, `<label>`, `<input>`, `<textarea>`

---

## Critères de validation

Le projet respecte les exigences suivantes :

- ✔ Validation W3C sans erreurs
- ✔ Utilisation correcte des balises sémantiques
- ✔ Images avec attribut `alt`
- ✔ Formulaire accessible avec `label`
- ✔ Code propre, indenté et commenté
